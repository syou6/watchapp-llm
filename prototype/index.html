これはUXプロトタイプです。 STT はブラウザの Web Speech API（ja-JP）、反応は実リポジトリの EchoReactionEngine と同じ発想のローカル生成。実機アプリでは STT が WhisperKit、反応が端末内 LLM（MLX + Qwen3-4B / Foundation Models）に置き換わります。ここで確かめられるのは「集音 → 文字起こし → 短い反応をストリーミング」という体験の流れと速度感です。
